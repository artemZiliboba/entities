# Entities

Открытая энциклопедия магических сущностей из сказок, мифов, легенд и литературных произведений.

Репозиторий является источником данных: каждое произведение хранится отдельным YAML-файлом, а интерфейс и индексы могут собираться автоматически поверх этих данных.

## Модель данных

Минимальная запись описывает произведение и найденные в нём сущности:

- `artifact` — магический предмет;
- `character` — магический персонаж;
- `creature` — сверхъестественное существо;
- `location` — магическая локация;
- `substance` — магическое вещество или пища;
- `plant` — магическое растение;
- `animal` — магическое животное;
- `spell` — заклинание или формула;
- `phenomenon` — магическое явление.

## Структура

```text
data/
  works/
    <tradition>/
      <work-id>.yaml
schema/
  work.schema.json
examples/
  catalog.md
```

## Пример

В `data/works/russian-folklore/the-frog-princess.yaml` находится пример сказки с несколькими магическими сущностями.

Человек редактирует YAML, а будущий GitHub Pages интерфейс сможет читать эти данные напрямую или получать собранный JSON-индекс через GitHub Actions.

## Добавление произведения

1. Создайте YAML-файл в `data/works/<tradition>/`.
2. Укажите метаданные произведения.
3. Добавьте все релевантные магические сущности в `entities`.
4. Используйте устойчивые английские `id` в kebab-case.
5. Не копируйте большие фрагменты защищённых авторским правом текстов; используйте краткое описание и библиографическую ссылку.

## GitHub Pages и темы

Сайт состоит из статических файлов и публикуется существующим GitHub Actions workflow без сборки. Пути к стилям, скриптам и данным относительные, поэтому сайт работает и по адресу `/<repository>/`.

Кнопка с луной/солнцем в шапке переключает светлую и тёмную темы. При первом посещении используется системная тема; ручной выбор сохраняется в `localStorage` отдельно для пути проекта. Если хранилище недоступно, переключатель продолжает работать в текущей вкладке. Цвета плавно меняются за 300 мс, а при `prefers-reduced-motion: reduce` анимация отключается. Скрипт `theme.js` подключён до стилей, чтобы применять сохранённую тему до отображения страницы.
