# Source Policy

## Source priority

Use the strongest available source for claims about what appears in a work:
1. Primary text in a reputable open edition.
2. Facsimile or scan of a recognized historical edition.
3. National-library, university, museum, or scholarly digital edition.
4. Reputable reference source for context or disambiguation.

Useful source families include Wikisource, Project Gutenberg, Internet Archive, national libraries, university repositories, and established scholarly collections.

## Evidence rules

- Every included entity must be identifiable in the chosen primary text or comparably strong source.
- Use secondary sources to clarify context, not to replace an available primary text.
- Do not rely on memory alone when making repository changes.
- Do not convert interpretation into fact; describe observable roles conservatively.
- Do not combine details from materially different variants into one record without explicit repository support.

## Copyright and quoting

Prefer public-domain texts. Paraphrase descriptions in original words. Do not copy long passages into YAML or PR bodies. A source URL and concise bibliographic note are normally sufficient.

## Reject a candidate when

- only low-quality summaries can be found;
- the text/variant cannot be reliably identified;
- magical entities would require speculation;
- the work is already present or pending in an open PR;
- source access is too incomplete for a confident full pass.
